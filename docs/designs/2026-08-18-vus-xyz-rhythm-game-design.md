# VUS XYZ 体感音游 · 设计文档

> 日期：2026-08-18
> 状态：已批准，进入实现
> 一句话：把音乐物理震动变成谱面，玩家在正确时间把手机甩到对应方向对齐波峰得分。

## 1. 核心概念

- 不预制 Note、不靠 AI 猜谱面：从**音频 FFT 能量峰**实时预生成谱面（`chart.json`），玩家用手机的 **XYZ 三轴加速度**去命中每个卡点目标。
- 丢任意 MP3 进去就能玩。
- 谱面离线生成一次；运行时只需读谱面 + 传感器 + 音频 + 判定 + 渲染。

## 2. 载体与环境

| 项 | 规格 |
|---|---|
| 设备 | 红米 9A（PowerVR GE8320, OpenGL ES 3.2） |
| 环境 | Termux + Termux:X11 + Termux:API |
| 语言 | VUS（自研编译器 + GUI + 插件系统） |
| 传感器 | 加速度计，经 termux-sensor 读 XYZ 三轴 |
| 音频 | 解码用 libmpg123；播放由 VUS 内建控制 |

## 3. 已确认的架构决策

1. **传感器接入**：为 VUS 新增 C 内建 `传感器_读`，运行时 fork `termux-sensor` 解析 JSON 实时读 XYZ（延迟低、作平台能力沉淀）。
2. **音频/计时**：由 VUS 内建控制 mpg123（启动/暂停/seek/进度），配 `时钟()` 毫秒基准做判定。
3. **谱面路线**：FFT 预生成谱面 `chart.json`，游戏按时间戳触发判定，非实时检测。
4. **实现形态**：方案一——并入 VUS 工具链一体化交付（`vus chart` 子命令 + 增能内建 + VUS 游戏脚本），零外部运行时依赖、单二进制。

## 4. 架构总览

```
vus chart <mp3> (离线, C):
  mp3 ─解码(libmpg123)─▶ PCM ─分帧 FFT─▶ 频段能量
  能量峰=卡点; 频段=轴; 幅值=目标 ─▶ 输出 chart.json

xyz_game.vus (在线, VUS 脚本):
  读 chart.json + 音频_播放 + 时钟基准
  每帧: 传感器_读 + 判定 + 渲染(复用 Guilite GUI)
```

## 5. 新增运行时内建 API（中文风格，与 图形_* 一致）

| 内建 | 签名/返回 | 说明 |
|---|---|---|
| `传感器_读` | (`轴`: "x"/"y"/"z") → 浮点 g | 实时加速度（termux-sensor fork 读 JSON） |
| `时钟` | () → 毫秒 int | 单调时钟基准，供判定时间差 |
| `音频_打开` | (`文件路径`) → 0/1 | 打开音频文件 |
| `音频_播放` | () | 开始/继续播放 |
| `音频_暂停` | () | 暂停 |
| `音频_跳转` | (`毫秒`) | seek 到指定位置 |
| `音频_进度` | () → 毫秒 int | 当前位置（驱动进度条） |
| `音频_时长` | () → 毫秒 int | 总时长 |

实现：在 `rt/` 以 C 实现并注册到编译器做参数类型校验，遵循现有 `图形_*` 机制。

## 6. 谱面格式 `chart.json`

```json
{
  "title": "示例歌曲",
  "bpm": 120,
  "duration_ms": 210000,
  "notes": [
    { "t": 5000, "axis": "Z", "target": 0.60 },
    { "t": 5240, "axis": "Z", "target": 0.55 }
  ]
}
```

- `t`：毫秒时间戳；`axis`：高亮轴（Z/X/Y）；`target`：判定目标（归一化能量峰幅值）。

## 7. 谱面生成流程（`vus chart <mp3> -o chart.json`）

1. libmpg123 解码 mp3 → PCM。
2. 分帧（1024 样本、50% 重叠）→ 加窗 → FFT → 频段能量。
3. 能量包络检测局部极大（波峰）= 卡点时刻 `t`。
4. 轴分配：由 FFT 主频段决定（低频→Z、中频→X、高频→Y），约束概率 Z55/X20/Y15/Combo10。
5. `target` = 峰值幅值归一化 × 系数。
6. 写出 `chart.json`。

## 8. 游戏判定与视觉（`xyz_game.vus`）

- 单帧循环：`now = 时钟()`、进度 = `音频_进度()`。
- 高亮轴 = 首个未到达判定窗口的 note 的 axis（一次只高亮一个）。
- 判定（与用户方案 3.3 一致）：

```
时间差 = abs(now - note.t)
if 时间差 < 判定窗口:
    差值 = abs(传感器_读(axis) - target)
    差值 < 容差×0.3 → PERFECT (+0.1x)
    差值 < 容差×0.6 → GREAT   (+0.1x)
    差值 < 容差      → GOOD    (+0.1x)
    else            → MISS    (连击清零, 倍率=1.0x)
else: MISS（错过判定窗口）
```

- 得分 = 100 × 当前倍率（用户方案 3.4：连击命中 +0.1x，上限 5.0x）。
- 视觉映射：折线波形/圆点（复用圆形）、圆角目标区间（已实现）、文字、进度条、命中文本上升淡出。

## 9. 第一版范围（YAGNI）

- **做**：`vus chart` 子命令；`rt/` 内建（`传感器_读`/`时钟`/`音频_*`）；`xyz_game.vus`；简易发光（多层呼吸圆环近似，不做 SDF shader）。
- **不做**：实时 FFT、GIF 命中特效、复杂 Combo 彩蛋动画。
- **错误处理**：传感器无权限/不可用 → 友好提示；音频/谱面缺失或格式坏 → 明确报错退出。
