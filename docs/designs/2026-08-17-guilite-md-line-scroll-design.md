# VUS GUI 图形能力拓展 —— 设计文档（图形_MD / 画线增强 / 滚动容器）

日期：2026-08-17
状态：已批准
批次：本批 = `图形_MD` + 画线增强 + 滚动容器；多页导航（含外部 .vus import 页）拆至下一批。

## 1. 目标

在既有 GUI 绘图基础层之上，本批发货三块单页绘制能力，满足更丰富的文本与布局需求：

1. 增强 `图形_画线`：支持线宽、虚线、终点箭头，且兼容旧 5 参脚本。
2. 新增 `图形_MD`：Markdown 最小集渲染，返回占用行数。
3. 新增滚动容器：带可视裁剪 + 内容平移的可滚动区域，滚轮/滑动自动 + 脚本控制。

多页导航（页面栈 + 编译期 import 外部 .vus 页面）单独进入下一批设计，不在此实现，避免单批过载。

## 2. 背景与决策

| 决策点 | 结论 |
|--------|------|
| 画线增强形态 | Bresenham + 方形笔线宽 + 虚线占空比 + 终点箭头，直接写 ARGB 帧缓冲 |
| 画线兼容 | 后 3 参（线宽/虚线/箭头）可省略，默认 `1/0/0`，旧 5 参脚本不破 |
| MD 子集 | 最小集：标题/无序有序列表/引用/代码块/段落与分隔线；行内标记当普通文本 |
| MD 样式表现 | 结构+颜色：去井号/加符号/缩进，标题用主题色、引用用边框色、代码用固定强调色；字号统一（外部字体批次再升级真粗体/字号） |
| MD 接口 | `图形_MD(x, y, 宽度, 文本) -> 行数`，复用 `draw_text_xy` 文字通道（X11 支持中文） |
| 滚动容器机制 | **内容平移 + 裁剪**：容器内所有绘制先减偏移 `dy` 再裁剪到可视矩形，脚本按原坐标画一遍即成滚动 |
| 滚动交互 | 平台滚轮/滑动自动作用于指针下容器 + 脚本 API（滚/偏移）显式控制 |
| 滚动条 | 内容高 > 可视高时右侧画简版位置指示条，可关闭 |
| 刷新 | 全部走脏标记 `vus_gui_mark_dirty`；绘制日志默认关闭仅调试输出 |

## 3. 总体架构

沿用既有三层（VUS 脚本 → generator 内建映射 → C 桥接层 → GuiLite surface/X11）。本批在桥接层新增三个能力模块，均复用现有主题变量与脏标记。

## 4. VUS 内建函数集（本批新增）

| 内建函数 | 桥接函数 | 说明 |
|----------|----------|------|
| `图形_画线(x1,y1,x2,y2,颜色[,线宽,虚线,箭头])` | `vus_gui_draw_line_ex` | 画线增强，多参兜底兼容 |
| `图形_MD(x, y, 宽度, 文本)` | `vus_gui_md` | Markdown 最小集渲染，返回占用行数 |
| `图形_滚动容器("名", x, y, 宽, 高, 内容高)` | `vus_gui_scroll_begin` | 登记可视区+滚动范围，开启裁剪 |
| `图形_滚动容器滚("名", dy)` | `vus_gui_scroll_delta` | 手动增/减偏移，返回新偏移 |
| `图形_滚动容器偏移("名")` | `vus_gui_scroll_offset` | 读当前偏移 |

## 5. 关键实现要点

- 画线：Bresenham 生成点序 → 每点 `width×width` 方形笔 → 虚线按固定占空跳过 → 箭头在终点端补两条短线。直接写 `vus_gui_surface_framebuffer()` 返回的 ARGB 帧缓冲，并置脏。
- MD：逐行解析标题(`#`)、有序/无序列表(`1. ` / `- `)、引用(`> `)、代码块(` ``` `，含语言行忽略)、空行段落、分隔线(`---`)；按宽度折行返回行数；颜色取当前主题 `s_theme`。
- 滚动容器：桥接层维护滚动容器状态（可视矩形、内容高、偏移、是否开启）。绘制函数（pixel/line/rect/fill/text/MD）在写帧缓冲前若处于活动容器，先做 `y -= offset` 平移再与可视矩形求交裁剪。滚轮事件 `vus_gui_platform_emit_wheel` 命中指针下容器时自动调整偏移并置脏。滚动条仅在内容高>可视高时绘制，可用 `图形_滚动容器滚` 关闭（offset 读写足够，不新增专开关）。

## 6. 错误处理

- 容器 `图形_滚动容器滚/偏移` 引用未登记名称：返回 `"0"`（或 `"-1"`），不崩溃。
- MD 文本为空：返回 `0` 行。
- 画线参数缺失：generator 用默认字面量补齐，越界安全（逐参判断参数个数）。
