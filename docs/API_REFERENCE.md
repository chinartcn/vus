## 1. 图形界面（graphics）

> 画布交互流，基于 **GuiLite**（`rt/guilite` + `rt/guilite_wrapper.cpp` + `rt/guilite_bridge.c` 桥接层 + `rt/guilite_platform.c` X11/headless 平台层，可选 `rt/guilite_gles.c` GLES 加速）。对应 Termux / Linux X11 平台；Android 组件流见第 13 章（VUA）。

所有 `图形_*` 函数需要在调用 `图形_初始化` 之后使用。
颜色统一使用 `0xRRGGBB` 格式整数（红/绿/蓝各 8 bit）。

### 1.1 初始化与窗口管理

#### `图形_初始化(宽, 高, 标题)`

- **说明**：初始化图形窗口，创建 X11 显示与帧缓冲。必须在所有其他 `图形_*` 函数之前调用。
- **参数**：
  - `宽`（整数）：窗口像素宽度
  - `高`（整数）：窗口像素高度
  - `标题`（字符串）：窗口标题
- **返回**：`"1"` 成功 / `"0"` 失败
- **示例**：
  ```vus
  图形_初始化(480, 340, "VUS 应用")
  ```

#### `图形_刷新()`

- **说明**：将帧缓冲内容上屏重绘，让已绘制的图形显示出来。
- **参数**：无
- **返回**：`"1"`
- **示例**：
  ```vus
  图形_填充(0, 0, 100, 50, 0xFF0000)
  图形_刷新()
  ```

#### `图形_保持()`

- **说明**：进入平台消息事件循环（GuiLite 平台层：X11 / headless）并保持窗口打开，直到用户关闭窗口。通常放在脚本末尾。
- **参数**：无
- **返回**：`"1"`
- **示例**：
  ```vus
  图形_初始化(320, 240, "Demo")
  图形_保持()
  ```

#### `图形_取事件()`

- **说明**：非阻塞处理平台事件队列（X11/headless），刷新点击/按键/鼠标坐标等交互状态。在主循环中调用。
- **参数**：无
- **返回**：`"1"`
- **示例**：
  ```vus
  当循环 真:
      图形_取事件()
      图形_刷新()
      睡眠(30)
  ```

### 1.2 基础绘图

#### `图形_画点(x, y, 颜色)`

- **说明**：在坐标 (x, y) 处绘制一个像素点。
- **参数**：`x`/`y`（整数坐标），`颜色`（0xRRGGBB）
- **返回**：`"1"`
- **示例**：`图形_画点(160, 120, 0xFF0000)`

#### `图形_画线(x1, y1, x2, y2, 颜色[, 线宽, 虚线, 箭头])`

- **说明**：从 (x1,y1) 到 (x2,y2) 绘制一条线段。可选参数：线宽（默认1）、虚线（默认0）、箭头（默认0）。
- **参数**：`x1`/`y1`/`x2`/`y2`（整数坐标），`颜色`，可选的 `线宽`/`虚线`/`箭头`
- **返回**：`"1"`
- **示例**：`图形_画线(0, 0, 100, 50, 0xFF0000, 3, 0, 1)`

#### `图形_矩形(x, y, 宽, 高, 颜色)`

- **说明**：绘制矩形外框。
- **参数**：`x`/`y`（左上角坐标），`宽`/`高`（尺寸），`颜色`
- **返回**：`"1"`
- **示例**：`图形_矩形(10, 10, 100, 60, 0x00FF00)`

#### `图形_填充(x, y, 宽, 高, 颜色)`

- **说明**：绘制填充实心矩形。
- **参数**：`x`/`y`（左上角坐标），`宽`/`高`（尺寸），`颜色`
- **返回**：`"1"`
- **示例**：`图形_填充(10, 10, 100, 60, 0x0000FF)`

#### `图形_文字(x, y, 文本, 颜色)`

- **说明**：在指定位置绘制一行文字。使用已加载的字体（若未加载字体则使用内置 8x8 位图字体）。
- **参数**：`x`/`y`（坐标），`文本`（字符串），`颜色`
- **返回**：`"1"`
- **示例**：`图形_文字(10, 20, "Hello", 0xFFFFFF)`

#### `图形_圆角矩形(x, y, 宽, 高, 半径, 颜色)`

- **说明**：绘制圆角矩形外框。
- **参数**：`x`/`y`/`宽`/`高`，`半径`（圆角半径像素），`颜色`
- **返回**：`"1"`
- **示例**：`图形_圆角矩形(10, 10, 120, 60, 12, 0x409FFF)`

#### `图形_圆角填充(x, y, 宽, 高, 半径, 颜色)`

- **说明**：绘制圆角填充实心矩形。
- **参数**：同上
- **返回**：`"1"`
- **示例**：`图形_圆角填充(10, 80, 120, 60, 12, 0x00FF00)`

#### `图形_画圆(圆心x, 圆心y, 半径, 颜色)`

- **说明**：绘制圆的外框。
- **返回**：`"1"`
- **示例**：`图形_画圆(160, 120, 40, 0xFF0000)`

#### `图形_填充圆(圆心x, 圆心y, 半径, 颜色)`

- **说明**：绘制实心圆。
- **返回**：`"1"`
- **示例**：`图形_填充圆(160, 120, 30, 0x0000FF)`

#### `图形_圆弧(圆心x, 圆心y, 半径, 起始角度, 跨角度, 颜色)`

- **说明**：绘制一段圆弧。起始角度 0 为正东（3 点钟方向）顺时针，跨角度可为负。
- **返回**：`"1"`
- **示例**：`图形_圆弧(160, 120, 40, 0, 90, 0xFFFF00)`

#### `图形_外观(圆角半径[, 抗锯齿])`

- **说明**：设置全局控件圆角半径。半径 > 0 时按钮等控件变成圆角外观。
- **返回**：`"1"`
- **示例**：`图形_外观(10)`

### 1.3 图片与动画

#### `图形_图片(x, y, 宽, 高, 路径)`

- **说明**：解码并绘制图片（PNG/SVG/GIF）到指定矩形区域，最近邻拉伸。
- **返回**：`"1"` 成功 / `"0"` 失败
- **示例**：`图形_图片(10, 10, 120, 80, "green.png")`

#### `图形_背景图(x, y, 宽, 高, PNG路径)`

- **说明**：解码 PNG 图片拉伸铺满指定区域，作为背景。
- **返回**：`"1"`
- **示例**：`图形_背景图(0, 0, 320, 240, "bg.png")`

#### `图形_动画_打开(名, 路径)`

- **说明**：打开一个 GIF 动画文件，把句柄存入槽表供复用。
- **返回**：`"1"` / `"0"`
- **示例**：`图形_动画_打开("加载", "loading.gif")`

#### `图形_动画_下一步(名, x, y)`

- **说明**：将指定 GIF 动画向前推进一帧并以原始像素尺寸绘制到 (x,y)。
- **返回**：`"1"` / `"0"`
- **示例**：`图形_动画_下一步("加载", 100, 150)`

#### `图形_动画_帧数(名)`

- **说明**：返回指定 GIF 动画的总帧数。
- **返回**：整数（字符串）
- **示例**：`帧数 = 图形_动画_帧数("加载")`

#### `图形_动画_关闭(名)`

- **说明**：关闭指定 GIF 动画并释放槽位。
- **返回**：`"1"` / `"0"`
- **示例**：`图形_动画_关闭("加载")`

### 1.5 页面栈（窗口管理器）

基于页面栈的多窗口/多页导航系统。每页定义一个约定式函数 `页_<页面名>()`，通过 `图形_页面_打开` 切换。

#### `图形_页面_打开(名)`

- **说明**：打开（压栈）指定页面。若该页已在栈中则弹出上层回到该页；否则压栈。
- **参数**：`名`（字符串，页面名称）
- **返回**：`"1"` / `"0"`
- **示例**：
  ```vus
  定义 页_设置():
      图形_填充(0, 0, 320, 240, 0x1a1f2e)
      图形_文字(10, 10, "设置页", 0xFFFFFF)

  图形_页面_打开("设置")
  ```

#### `图形_页面_返回()`

- **说明**：从当前页面返回上一级页面（弹栈）。
- **返回**：`"1"`（有上一页） / `"0"`（已在首页）
- **示例**：`图形_页面_返回()`

#### `图形_页面_当前()`

- **说明**：返回当前所在页面的名称字符串。
- **返回**：页面名字符串；无页面返回空串
- **示例**：`页 = 图形_页面_当前()`

#### `图形_页面_绘制()`

- **说明**：重新绘制当前页面的内容（调用 `页_<名>()` 函数体）。
- **返回**：`"1"` / `"0"`（无当前页或函数缺失）
- **示例**：`图形_页面_绘制()`

### 1.6 控件

#### `图形_按钮(名, x, y, 宽, 高, 文本)`

- **说明**：创建并绘制按钮，登记命中矩形供 `图形_按钮点击` 检测。
- **参数**：`名`（控件ID），`x`/`y`/`宽`/`高`，`文本`（按钮文字）
- **返回**：`"1"`
- **示例**：`图形_按钮("开始", 50, 80, 120, 40, "确定")`

#### `图形_按钮点击(名)`

- **说明**：检测指定按钮是否被点击。需配合 `图形_取事件()` 和 `图形_按钮()` 使用。
- **返回**：`"true"` / `"false"`
- **示例**：
  ```vus
  如果 图形_按钮点击("开始") == "true" 则
      打印("点击了开始")
  结束
  ```

#### `图形_标签(名, x, y, 文本, 颜色)`

- **说明**：绘制静态文本标签控件。
- **返回**：`"1"`
- **示例**：`图形_标签("标题", 10, 10, "Hello", 0xFFFFFF)`

#### `图形_文本框(名, x, y, 宽, 高, 文本)`

- **说明**：绘制文本框控件，显示用户输入内容。
- **返回**：`"1"`
- **示例**：`图形_文本框("输入框", 10, 60, 200, 30, "")`

#### `图形_复选框(名, x, y, 文本, 选中)`

- **说明**：绘制复选框。`选中` 为 1 表示勾选。
- **返回**：`"1"`
- **示例**：`图形_复选框("记住", 10, 90, "记住密码", 1)`

#### `图形_进度(名, x, y, 宽, 高, 值)`

- **说明**：绘制进度条。`值` 为 0~100 表示百分比。
- **返回**：`"1"`
- **示例**：`图形_进度("进度1", 10, 120, 200, 16, 45)`

#### `图形_圆环(名, x, y, 半径, 比例[, 颜色])`

- **说明**：绘制圆环进度条。`比例` 0~100 表示填充百分比，颜色可省略。
- **返回**：`"1"`
- **示例**：`图形_圆环("环1", 160, 120, 40, 65, 0x409FFF)`

#### `图形_卡片(名, x, y, 宽, 高, 标题)`

- **说明**：绘制卡片容器，附带标题文字。
- **示例**：`图形_卡片("card1", 10, 20, 200, 120, "设置")`

#### `图形_面板(名, x, y, 宽, 高, 标题)`

- **说明**：绘制面板容器，附带标题文字。
- **示例**：`图形_面板("panel1", 10, 20, 200, 120, "面板")`

#### `图形_表单行(名, 标签, x, y, 宽, 文本)`

- **说明**：绘制表单一行：左侧标签 + 中间输入框 + 右侧文本。
- **示例**：`图形_表单行("行1", "用户名", 10, 50, 200, "admin")`

#### `图形_行点击(名)`

- **说明**：检测某一行是否被点击。
- **返回**：`"true"` / `"false"`
- **示例**：`如果 图形_行点击("行1") == "true" 则 ... 结束`

#### `图形_模拟点击(x, y)`

- **说明**：注入一次模拟点击坐标，用于 headless 测试。
- **示例**：`图形_模拟点击(100, 80)`

### 1.12 Markdown 文字渲染

#### `图形_MD(x, y, 宽度, 文本)`

- **说明**：以最小 Markdown 子集渲染文本（标题/列表/引用/代码块/分隔线），按宽度折行。
- **返回**：占用行数（整数）
- **示例**：

## 8. 网络请求（HTTP）

桌面构建基于 libcurl（需 `VUS_HAVE_CURL` + `-lcurl`）；**Android APK 由 Java 平台桥实现**（`http.get`/`http.post`/`http.request`/`http.upload`），无需额外依赖。

#### `网络_GET(URL)`

- **说明**：发送 HTTP GET 请求。支持 http/https 链接。
- **返回**：响应体文本（字符串）
- **示例**：`响应 = 网络_GET("https://api.example.com/data")`

#### `网络_POST(URL, 数据)`

- **说明**：发送 HTTP POST 请求。`数据` 为请求体字符串。
- **返回**：响应体文本（字符串）
- **示例**：`响应 = 网络_POST("https://api.example.com/post", "key=value")`

#### `网络_请求(方式, 地址, 头JSON, 数据, 超时秒, 重试次数)`

- **说明**：通用 HTTP 请求（认证/超时/重试）。`方式` 为 `GET`/`POST`；`头JSON` 传入自定义请求头（如 `{"Authorization":"Bearer <token>"}` 做 token 认证）；`数据` 为 POST 请求体；`超时秒` 与 `重试次数` 可省略（默认 30 秒 / 0 次，APK 侧默认重试 2 次）。APK 全参生效；桌面回退 curl（忽略头/超时/重试）。
- **返回**：响应体文本（字符串）
- **示例**：
  ```vus
  响应 = 网络_请求("GET", "https://api.example.com/user",
                  "{\"Authorization\":\"Bearer abc123\"}", "", 30, 2)
  ```

#### `文件_上传(地址, 本地文件, 字段JSON, 头JSON)`

- **说明**：multipart/form-data 文件上传。`本地文件` 为相对应用 `filesDir` 或绝对路径；`字段JSON` 为附加表单字段；`头JSON` 自定义请求头。
- **返回**：`"1"` 成功 / `"0"` 失败（**APK 专属能力**；桌面回退 curl `-F file=@路径` 且仅传文件）。
- **示例**：`结果 = 文件_上传("https://api.example.com/upload", "photo.jpg", "{\"标签\":\"头像\"}", "")`

#### `网络_下载(URL, 路径)`

- **说明**：下载 URL 指向的文件到本地路径。
- **返回**：`"1"` 成功 / `"0"` 失败
- **示例**：`网络_下载("https://example.com/file.zip", "/sdcard/file.zip")`

> **状态：已实现（v1.0-beta）**。属于 **Android 组件解析流**，与第 1 章 `图形_*`（GuiLite 画布流：Termux/Linux X11）是**两套独立 UI 机制**，勿混谈。
> 每屏 = 一个 `.vua` 文件（或 `界面_显示_JSON` 的 JSON 字符串）；`.vus` 用本组函数做多屏导航与事件绑定。界面定义语言见 [VUA_REFERENCE.md](VUA_REFERENCE.md)，native→Java 渲染树见 [VUA_RENDER_TREE.md](VUA_RENDER_TREE.md)，native 接口见 `rt/vua.h`。
> 实现链路：`.vus` 函数（`src/generator.c` 映射）→ `rt/vua.c`（`VuaSession` 屏栈）→ 规范化渲染树 → APK 壳 `VuaRenderer.java` 建 Android View → 触摸回传 `vua_trigger_event`/`vua_trigger_by_id`。

所有函数作用于"当前屏（屏栈栈顶）"，全局 session 线程管理整个屏栈。

### 13.1 多屏导航

#### `界面_显示(路径)`

- **说明**：读取指定 `.vua` 文件，解析为一屏并入栈为当前屏，通知 Java 重渲染（`vua_session_show`）。
- **返回**：`"0"` 成功 / 错误串
- **示例**：
  ```vus
  界面_显示("主界面.vua")
  ```

#### `界面_显示_JSON(串)`

- **说明**：把 `.vua` 格式的 JSON **字符串**直接解析为一屏并入栈（`vua_show_json`）。用于运行时根据数据动态组装的界面（动态渲染树）。
- **返回**：`"0"` 成功 / 错误串

#### `界面_返回()`

- **说明**：从屏栈弹出一屏，回到上一屏并重渲染（`vua_session_back`）；已在最底屏时不弹。
- **返回**：`"0"` 成功 / 错误串
- **示例**：`界面_返回()`

#### `界面_返回至(名)`

- **说明**：从屏栈弹到指定 `.vua` 名的那一屏（`vua_session_back_to`，按屏名匹配，找不到则无操作）。
- **返回**：`"0"` 成功 / 错误串

### 13.2 事件绑定与派发

#### `界面_绑定(事件名, 处理函数)`

- **说明**：把 `.vus` 里定义的一个处理函数登记为当前屏该事件名的处理器（`vua_on`；编译期包成 `VusClosure`），同名重复登记以最近一次为准。
- **返回**：`"0"` 成功 / 错误串
- **示例**：
  ```vus
  定义 保存进度():
      打印("已保存")

  界面_显示("进度.vua")
  界面_绑定("保存进度", 保存进度)
  ```

> 其余派发入口已由 `.vus` 内置函数接线（`src/generator.c`）：
>
> | `.vus` 调用 | 运行时 | 说明 |
> |------------|--------|------|
> | `界面_触发(事件名[, 变量JSON])` | `vua_trigger_event` | 程序化派发事件（绕过 Java 触摸回传）；`变量JSON` 为 `{"键":"值"}` 对象字符串，缺省不携带参数 |
> | `界面_按ID触发(控件id[, 变量JSON])` | `vua_trigger_by_id` | 按渲染树节点 `id` 解析事件后派发（与 `triggerId` 路径一致） |
> | `界面_解绑(事件名)` | `vua_off` | 从事件表移除已登记处理函数（未登记则无操作） |
> | `界面_全局置(键, 值)` | `vua_session_global_set` | 写会话级全局变量（跨屏共享，写屏状态用 `界面_设置`） |
> | `界面_全局取(键)` | `vua_session_global_get` | 读会话级全局变量；缺失返回空串 `""` |
>
> 触发类入口同时仍由 Java 触摸回传（JNI）调用。本组已实现并可用：`界面_显示` `界面_显示_JSON` `界面_返回` `界面_返回至` `界面_绑定` `界面_设置` `界面_取` `界面_触发` `界面_按ID触发` `界面_解绑` `界面_全局置` `界面_全局取`。

### 13.3 屏内变量（已实现）

#### `界面_设置(变量名, 值)`

- **说明**：写入当前屏变量状态（`vua_state_set_cstr`）；带 `变量` 的文本控件会在重渲染时回填显示值。
- **返回**：`"0"`
- **示例**：
  ```vus
  界面_设置("计数", 转文本(计数))
  ```

#### `界面_取(变量名)`

- **说明**：读取当前屏变量当前值（`vua_state_get_or_empty_cstr`）。
- **返回**：变量值（字符串）；不存在返回 `""`
