## 一、概述

VUS 是一门**中西合璧的编程语言**（中文关键字 + 拼音/英文混合，无缝转译生成 C 代码），主要面向
**轻量脚本、桌面 GUI、Andriod/VUA 组件流**三块能力区间。自 2026-07-21 初始化 v0.1 起，到
2026-09-04 **v3.0 首个正式版**发布，仅用约 45 天完成从原型到可落地生产、并可打包成 APK 的分水岭。

## 四、代码库结构与架构

- **`src/`**：编译器管线——`lexer → parser → generator` + AST/Token，以及 `vus_apk`、`vus_chart`、`vus_vaz`(模板)、`vus_vusx`(流水线)、`vus_plugin`、`vus_lang`(多语)、LSP 子模块。
- **`rt/`**：运行时（`libvus_rt`）+ 协程 `vus_coro` + GUI + yyjson + easylogger；`.vua` 生成 C 直接编入。
- **`tests/`**：86 个 `.vus` 端到端/回归用例（含多返回、await、闭包、f-string、复合赋值、容器释放、字典遍历等）。
- **`examples/`**：Hello、综合演示、GUI 全控件、VUS-OS、插件示例等 14 个。
- **`docs/`**：40 个文件 / ≈7,400 行（见下）。
- **`examples/vua-android/`**：完整 Android 工程（VUA 渲染器、Java 能力桥、ExtensionLoader DEX 插件、UpdateManager 热更、构建/Pack 脚本）。

## 五、语言与平台能力演进

**语言特性**
基础：变量/四则/流程/函数/字符串/列表/字典/类；转译生成 C。
进阶（09-05 补强）：多返回值、真 await（协程）、闭包/函数一等公民、f-string 插值、复合赋值（`+= -= *= /= %= ..=`）、字典遍历接口、`vus_unref` 递归释放（环引用防护）。

**桌面 GUI**：GuiLite 基础层 + **Xft 中文 UTF-8 渲染**、CJK 字体候选、双缓冲刷新；全部控件如标签/文本框/进度条/列表/画布；`.vaz` 控件模板与多页导航。

**Android/VUA**：VUA 组件流运行时、声明式 `.vua` 渲染树、Java 平台能力桥（网络/文件/上传由 Java 暴露）、动态构建渲染树、长列表虚拟化/富文本/远程图缓存；**DEX 插件动态加载（ExtentionLoader）**与 **.so/.vua/.dex 热更新协议（UpdateManager）**；多 ABI（arm32/arm64/x86_64）构建。

**性能**：渲染合并、数值解析短路、转文本转发、列表/字典装箱 helper、concat 免二重复制。
