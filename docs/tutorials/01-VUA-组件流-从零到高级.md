# VUA 组件流：从零到高级（Android）

> 本文是 VUS Android 组件流（VUA）的完整实战教程。
> 先决条件：会写最基础的 VUS（变量/函数/`如果`），快速入门见 [TUTORIAL.md](../TUTORIAL.md) 第 1~5 章。
> 规范细节见 [VUA_REFERENCE.md](../VUA_REFERENCE.md)；渲染树格式见 [VUA_RENDER_TREE.md](../VUA_RENDER_TREE.md)。

---

## 1. VUA 是什么

VUS 提供两套互不借用的 GUI 机制：

| 机制 | 运行环境 | 界面怎么来 | 驾驶函数 |
|------|----------|------------|----------|
| **画布流**（`图形_*`） | Termux / Linux X11 | 代码逐帧绘制 | `图形_初始化`/`图形_保持` |
| **组件流（VUA）** | Android APK | `.vua` JSON 声明界面 | `界面_*` |

VUA 的链路一句话讲完：

```
.vus 逻辑脚本（testdata/vua_test.vus）
   │  界面_显示("vua_home.vua") / 界面_绑定("事件名", 函数)
   ▼
native vua.c（解析/校验/多屏栈/事件表）
   │  渲染树 JSON（vua_screen_dump_rendertree）
   ▼
Java VuaRenderer（JSON → Android View 树）
   │  你触摸 → vuaTrigger(事件名, 变量JSON)
   ▼
.vus 事件函数（界面_设置/界面_取 改状态，或界面_显示 换屏）
```

界面是**声明式**的：`.vua` 文件描述"长什么样"，`.vus` 文件描述"点下去怎么办"。

## 3. 解剖一个页面（`.vua`）

`vua_home.vua` 是标准页面，结构为**一个界面节点 + 子组件数组**：

```json
{
  "type": "界面",
  "标题": "主页",
  "子组件": [
    { "type": "文本", "内容": "你好，VUS + VUA Android" },
    { "type": "按钮", "id": "btn_adv", "文字": "高级能力演示",
      "事件": { "事件名": "打开高级", "回调变量": [] } },
    { "type": "输入框", "id": "in1", "variable": "备注", "标签": "备注", "提示": "输入备注" }
  ]
}
```

要点：

- **`type`**：控件类型，必须是 `vua_controls.json` 已登记的（中文）或等价的英文别名（`界面/列/行/卡片/文本/按钮/输入框/复选框/开关/滑块/下拉/图片/列表/网页/课表`）。
- **`id`**：控件唯一标识，事件分发（`vuaTriggerById`）和输入取值用。
- **`variable`**：输入控件的值绑定名。`界面_取("备注")` / 事件收集变量都按这个名字取。
- **`事件.事件名`**：点击时要触发的 VUS 事件；`事件.回调变量` 是"键=值"参数（如 `"星级=3"`）。
- 容器（`界面/列/卡片/表单`）用 `"子组件": [...]` 嵌套；输出文本用 `"内容"`，按钮用 `"文字"`。

## 4. 驾驶函数：`界面_*`

| 函数 | 作用 | 示例 |
|------|------|------|
| `界面_显示("vua_home.vua")` | 切到（压栈）指定页面 | `界面_显示("vua_advanced.vua")` |
| `界面_显示_JSON(树字符串)` | 动态上屏一整棵渲染树 | 见 §11 动态渲染树 |
| `界面_绑定("事件名", 函数名)` | 把控件触发的事件接到 VUS 函数 | `界面_绑定("打开高级", 事件_打开高级)` |
| `界面_设置("变量", 值)` | 修改变量（页面文本/输入框随之刷新） | `界面_设置("计数", 转文本(新值))` |
| `界面_取("变量")` | 读变量当前值 | `界面_取("计数")` |
| `界面_返回()` / `界面_返回至(名)` | 返回上一屏 / 返回至指定屏 | `界面_返回()` |

典型 `vua_test.vus` 启动段：

```vus
定义 事件_打开高级():
    界面_显示("vua_advanced.vua")
    界面_绑定("返回主页", 事件_返回主页)
    界面_绑定("选择记录", 事件_选择记录)
    界面_绑定("加载更多", 事件_加载更多)

定义 事件_返回主页():
    界面_返回()

界面_显示("vua_home.vua")
界面_绑定("打开高级", 事件_打开高级)
```

流程：脚本启动 → 显示主页 → 绑定按钮事件 → 用户在 APK 里点"高级能力演示" → `vuaTrigger("打开高级")` → 执行 `事件_打开高级` → 换屏 + 绑定该屏事件。

> **重要**：每次换屏都要重新绑定**本屏**用到的事件（页面栈顶切换后事件表是当前屏的）。

## 5. 事件与变量链路

### 5.1 按钮 → 事件函数

点击按钮时，Java 侧会带上一包变量 JSON 触发事件，VUS 函数按名接收：

```vus
定义 事件_选择记录(下标, 值):
    界面_设置("选中记录", "第 " + 下标 + " 行：" + 值)
```

列表行点击自动带 `下标` 和 `值`（行标题）。普通按钮带 `事件.收集变量` 里列出的输入控件值。

### 5.2 输入框 → 计数示例（vua_logic.vua）

```vus
定义 事件_加1():
    界面_设置("计数", 转文本(转数字(界面_取("计数")) + 1))
```

输入框声明 `"variable": "计数"` 后，`界面_取("计数")` 读的是输入框当前内容；
`界面_设置("计数", ...)` 会回填输入框（或文本控件）。

### 5.3 回调变量（字面量参数）

`.vua` 里给事件带常数：

```json
{ "type": "按钮", "文字": "★", "事件": { "事件名": "调整星级", "回调变量": ["星级=3"] } }
```

```vus
定义 事件_调整星级(变量, 值):
    界面_设置(变量, 值)
```

VUS 函数参数名与变量 JSON 的键一致即可（`变量`→`"星级"` 的键，`值`→`"3"` 的值）。

## 6. 多屏导航与页面缓存

- 屏栈：`界面_显示` 压栈、`界面_返回` 弹栈；返回栈空则回 Android 空白页。
- **页面 View 缓存**：渲染器按渲染树指纹缓存整棵页面（上限 6 页，LRU）。换回已缓存页直接复用 View，输入状态保留。
- **同屏增量更新**：同一屏内只改变量值时，渲染器只 `setText` 变化文本，不重建整树。

```vus
定义 事件_返回主页():
    界面_返回()          # 弹栈回主页；主页 View 缓存命中，秒回
```

## 7. 列表控件（长列表不卡的关键）

> 老问题：界面里嵌整棵 LinearLayout 树，列表项一多、View 数量线性涨，滑动必卡。
> 现在的 `列表` 控件由 **ListView + Adapter** 实现，`getView` 走 `convertView` **复用**：
> View 数量只与屏幕高度有关、与数据条数无关——滑出屏幕的行回收重用。

### 7.1 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `数据` | ✅ | 数组：元素是字符串（只显示标题）或 `{"标题","副标题","图片"}` |
| `高度` | | dp 单位；默认 480，超出部分内部滚动 |
| `事件.事件名` | | 行点击事件，自动带 `下标`/`值`（行标题） |
| `加载更多` | | 滚动到底自动触发的事件名（分页逻辑写在 .vus 里） |

### 7.2 示例（vua_advanced.vua）

```json
{
  "type": "列表", "id": "lst",
  "加载更多": "加载更多",
  "事件": { "事件名": "选择记录" },
  "高度": 420,
  "数据": [
    { "标题": "记录 00", "副标题": "副标题 00" },
    { "标题": "记录 01", "副标题": "副标题 01" }
  ]
}
```

### 7.3 事件处理

```vus
# 行点击：自动收到 下标 / 值
定义 事件_选择记录(下标, 值):
    界面_设置("选中记录", "第 " + 下标 + " 行：" + 值)

# 滚动到底：分页在这里做（本示例只计数演示）
定义 事件_加载更多():
    次数 = 转数字(界面_取("列表提示计数"))
    次数 = 次数 + 1
    界面_设置("列表提示计数", 转文本(次数))
    界面_设置("列表提示", "已触发加载更多 " + 转文本(次数) + " 次")
```

> **防重入**：`加载更多` 由渲染器的滚动监听触发，持续停留底部不会连环触发；
> 真实分页请在事件里 `网络_请求` 拉下一页数据后，把新数据 `追加` 到列表源再
> `界面_设置` 刷新（或 `界面_显示_JSON` 重建列表节点）。

### 7.4 行内图片

`数据` 项带 `"图片": "https://..."` 时，行首渲染缩略图（**异步加载 + 缓存**，不卡滚动），
无图或非 http 时自动隐藏。

## 8. 网页 / 富文本控件

> 解决"渲染 HTML/Markdown"。渲染树加 `网页` type，Java 侧用 WebView 承载；
> **页面内 JS 通过 `window.vus` 桥把事件接回 VUS**。

### 8.1 三种内容输入

| 字段 | 说明 |
|------|------|
| `url` | 直接加载网址（WebView） |
| `html` | 渲染完整 HTML 片段 |
| `内容` | 按 Markdown 子集渲染：`# 标题`、`**粗体**`、`*斜体*`、`- 列表`、`> 引用`、```` ``` 代码块 ````、`[链接](url)` |

```json
{ "type": "网页", "内容": "# 你好\n\n**加粗** 与 *斜体*\n\n- 项一\n- 项二", "高度": 340 }
```

### 8.2 事件回接：JS → VUS

页面内脚本即可触发 VUA 事件：

```js
// 网页的 JS
window.vus.onEvent("保存", '{"正文":"Hello"}');   // 按事件名触发
window.vus.triggerById("btn_save", '{}');          // 按控件 id 触发
```

VUS 侧照常绑定：

```vus
界面_绑定("保存", 事件_保存)
定义 事件_保存(正文):
    打印(正文)   # "Hello"
```

链路：`WebView JS` → `@JavascriptInterface` → `VuaBridge.postToTrigger`
（自动切主线程）→ `vuaTrigger` → `.vus` 处理函数。**JS 回调跨线程已统一处理**，
不会出现 JNI 跨线程问题。

> 安全性提示：`setJavaScriptEnabled(true)`。只加载可信内容；
> 远程 `url` 建议自行校验来源。

## 9. 图片控件（本地 + 远程异步缓存）

```json
{ "type": "图片", "src": "https://example.com/logo.png", "宽": 160, "高": 160 }
```

- **http/https**：异步下载 + 内存 LruCache + 磁盘缓存（应用缓存目录）；加载中不阻塞 UI。
  滚动列表时用 tag 防止错位（旧请求结果不会占新位置）。
- **相对路径**：相对应用 `filesDir`（`extractAssets` 已释放到该目录），同步解码。
- **失败**：显示 `[图片] <src>` 占位文本。
- 列表行图片见 §7.4，字段与独立图片一致。

实现参考 `ImageLoader.java`（线程池 3、内存 1/8 堆、磁盘 `cacheDir/img/<md5>`）。

## 10. 课表控件（表格）

```json

  "星期": ["周一","周二"],
  "节次": ["第1节","第2节"],
```

## 11. 动态渲染树（`界面_显示_JSON`）

从网络/文件拉数据后**运行时拼界面**：

```vus
定义 事件_加载课表():
    数据 = 网络_GET("https://gitee.com/rtccn_mc/vus/raw/master/apk_class.json")
    如果 数据 == "":
        打印("课表下载失败")
        返回
    结束
    标题 = 对象文本(JSON_查询(数据, "标题"))
    星期串 = JSON_生成(JSON_查询(数据, "星期"))
    节次串 = JSON_生成(JSON_查询(数据, "节次"))
    课程串 = JSON_生成(JSON_查询(数据, "课程"))
    树 = "{\"type\":\"界面\",\"标题\":\"" + 标题 +
         "\",\"子组件\":[{\"type\":\"课表\",\"标题\":\"" + 标题 +
         "\",\"星期\":" + 星期串 + ",\"节次\":" + 节次串 +
         ",\"课程\":" + 课程串 + "}]}"
    界面_显示_JSON(树)
```

要点：`JSON_查询` 取字段 → `对象文本` 转字符串 → `JSON_生成` 序列化数组 →
拼一棵完整渲染树字符串 → `界面_显示_JSON` 上屏。列表分页等"数据驱动界面"同理。

## 12. 网络强化（认证/超时/重试/上传）

组件流里联网直接调 VUS 网络函数（APK 由 Java 平台桥实现，**无需任何 C 依赖**）：

```vus
# 带 token 的认证请求（自定义请求头）
用户 = 网络_请求("GET", "https://api.example.com/user",
                "{\"Authorization\":\"Bearer abc123\"}", "", 15, 2)

# multipart 文件上传（相对 filesDir 或绝对路径）
结果 = 文件_上传("https://api.example.com/upload", "photo.jpg",
              "{\"说明\":\"头像\"}", "")
```

详细见 [02-网络与文件实战](02-网络与文件实战.md)。

## 13. DEX 逻辑拓展（可选）

`.vus` 可调 Java 侧动态加载的 DEX 插件（逻辑热更新，配合 `网络_下载`）：

```json
效果 = 拓展_调用("sample.sum", "{\"a\":11,\"b\":22}")
```

插件 dex 放 `filesDir/plugins/`，APK 内置 `assets/plugins/sample.dex`。
响应 `{"ok":true,"data":...}`，用 `JSON_查询`/`对象文本` 取结果。桌面/纯 native 返回空串。

## 14. 完整走一遍（建议顺序）

1. 进主页：`界面_显示("vua_home.vua")` + 绑定导航按钮。
2. 读 `vua_logic.vua` 学会输入/计数/回调变量。
3. 建自己的 `列表` 页：先写静态 `数据` 数组 → 加 `事件` → 加 `加载更多`。
4. 用 `网页` 渲染一篇 Markdown；在 JS 里 `window.vus.onEvent` 回传。
5. 加一张网络图，体验异步缓存。
6. 网络数据驱动：`网络_请求` → `JSON_查询` → `界面_显示_JSON`。

每一步改 `testdata/` 下的 `.vua`/`.vus`，重建 APK（[03-APK-构建与发布](03-APK-构建与发布.md)）即可上机验证。
