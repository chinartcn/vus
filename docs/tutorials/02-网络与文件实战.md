# 网络与文件实战

> 覆盖 VUS 网络/文件能力的完整实操：认证、超时/重试、上传、下载、文件读写，
> 以及**桌面（libcurl）与 Android APK（Java 平台桥）两端的差异**。
> 语法与函数清单见 [API_REFERENCE.md](../API_REFERENCE.md) 第 8、9 章。

---

## 1. 网络函数家族

| 函数 | 做什么 | 桌面依赖 |
|------|--------|----------|
| `网络_GET(URL)` | GET，返回响应体文本 | libcurl + `VUS_HAVE_CURL`，缺失自动回退系统 `curl` 命令 |
| `网络_POST(URL, 数据)` | POST，`数据` 为请求体 | 同上 |
| `网络_请求(方式, 地址, 头JSON, 数据, 超时秒, 重试次数)` | 通用：自定义请求头（token 认证）、超时、重试 | 回退系统 `curl` 命令（忽略头/重试，应用超时） |
| `文件_上传(地址, 本地文件, 字段JSON, 头JSON)` | multipart 文件上传 + 附加字段 | 回退 `curl -F`（仅文件） |
| `网络_下载(URL, 路径)` | 下载到本地文件 | libcurl + `VUS_HAVE_CURL`，缺失自动回退系统 `curl` 命令 |

**关键差异**：

| 端 | 实现 | 注意 |
|----|------|------|
| 桌面 | `rt/libvus_rt.c` → libcurl | 需 `libcurl-dev`，编译带 `-DVUS_HAVE_CURL -lcurl`；缺失时自动回退系统 `curl` 命令（`网络_请求` 忽略头/重试，应用超时） |
| APK | `VuaBridge.callJava` → `http.get/post/request/upload/download` | **全部参数生效**，无外部依赖；HTTP 在主线程调用时会自动转子线程等待 |

返回约定：**响应体是原始文本**（APK 侧 Java 桥的 `{"ok":true,"data":...}` 包装由运行时自动解包，VUS 拿到的是 `data` 本体）；请求失败（网络不可用/非 200/超时重试耗尽）返回**空串**。`文件_上传`/`网络_下载` 成功返回 `"0"`、失败返回 `"-1"`（`文件_上传` 桌面端返回服务器响应文本）。

## 2. token 认证实战

论坛/API 最常需要的认证头，用 `网络_请求` 一站解决：

```vus
token = "Bearer eyJhbGciOi..."            # 登录后拿到的凭证

# 拉当前用户信息（自定义 Authorization 头）
用户 = 网络_请求("GET", "https://api.example.com/user",
              "{\"Authorization\":\"" + token + "\"}", "", 30, 2)

# 返回的仍是响应体原文：JSON 服务端字段直接取（无 ok/data 包装）
如果 用户 == "":
    界面_设置("欢迎", "请求失败（网络/超时/非 200）")
否则:
    名字 = 对象文本(JSON_查询(用户, "name"))
    界面_设置("欢迎", "你好，" + 名字)
结束
```

- 头 JSON 是**一个 JSON 对象字符串**，键值对即请求头。
- 转发/拼接字符串时注意转义：`"{\"Authorization\":\"...\"}"`。

用 `网络_POST` 带 token 提交表单：

```vus
回复 = 网络_请求("POST", "https://api.example.com/topic/1/reply",
              "{\"Authorization\":\"" + token + "\"}",
              "content=写得真好&tags=vus", 30, 2)
```

> 桌面端没有请求头能力，认证类逻辑请以 APK 侧为准；桌面调试可改用 `网络_GET` 直连无鉴权地址。

## 3. 超时与重试

`网络_请求` 的第 5、6 个参数：

| 参数 | 默认 | 说明 |
|------|------|------|
| `超时秒` | 30（桌面）/ 30（APK 连接+读取均套用） | 超过即失败 |
| `重试次数` | 0（桌面忽略）；APK 侧默认为 2 | 失败后重试，上限 10 |

```vus
# 慢网环境：超时 15s、失败重试 3 次
数据 = 网络_请求("GET", "https://api.example.com/slow", "", "", 15, 3)
```

APK 侧实现（`VuaBridge.doHttp`）：每次 attempt 独立建立连接，
连接+读取超时都套 `超时秒`，网络错误/超时按次数重试；主线程调用自动切线程同步等待。

## 4. multipart 文件上传

```vus
# 上传 filesDir 下的 photo.jpg，附带表单字段"说明"
结果 = 文件_上传("https://api.example.com/upload", "photo.jpg",
              "{\"说明\":\"头像\"}", "{}")

# 绝对路径也可以
结果 = 文件_上传("https://api.example.com/upload", "/sdcard/Pictures/a.png", "{}", "")

如果 结果 == "1":
    打印("上传成功")
否则:
    打印("上传失败（路径不存在 / 网络错误）")
结束
```

实现细节（APK，`VuaBridge.doUpload`，无第三方库）：

- 手写 `multipart/form-data`：`--boundary` 分隔每个 part；
- 附加字段：`Content-Disposition: form-data; name="<字段名>"`；
- 文件部分：`name="file"; filename="<文件名>"` + `application/octet-stream`；
- 时间戳生成 boundary，避免并发冲突；支持自定义头（如 `Authorization`）。

相对路径解析：相对应用 `getFilesDir()`；绝对路径原样使用。路径不存在返回失败。

## 5. 文件操作全家桶

```vus
# 写 / 读 / 追加 / 判断 / 删除 / 列目录
文件_写入("note.txt", "第一行\n")
内容 = 文件_读取("note.txt")
文件_追加("note.txt", "第二行\n")
如果 文件_存在("note.txt"):
    打印("存在")
结束
目录 = 文件_列表(".")
文件_删除("note.txt")
```

APK 侧同样是 Java 平台桥（`file.read/write/append/exists/delete/list/isdir`），
相对路径解析同上传（相对 `filesDir`）。

与 `网络_下载` 组合做"下载后处理"：

```vus
# 下载远程 zip 到本地
网络_下载("https://example.com/data.zip", "下载/data.zip")
如果 文件_存在("下载/data.zip"):
    打印("已下载，字节数：" + 文本_长度(文件_读取("下载/data.zip")))
结束
```

> `网络_下载` 的目标路径：APK 相对 `filesDir`、桌面相对 cwd，父目录自动创建；成功 `"0"`、失败 `"-1"`。

## 6. 完整实战：登录 → 带 token 拉数据 → 下载 → 上传

一个论坛场景串起来的例子（假设 VUA 页面有输入框 `variable="账号"`/`"密码"`）：

```vus
定义 事件_登录():
    账号 = 界面_取("账号")
    密码 = 界面_取("密码")
    # 1) POST 登录拿 token
    响应 = 网络_POST("https://api.example.com/login",
                    "name=" + 账号 + "&pass=" + 密码)
    如果 响应 == "":
        界面_设置("状态", "网络不可用")
        返回
    结束
    token = "Bearer " + 对象文本(JSON_查询(响应, "token"))
    # 2) 带 token 拉用户资料
    资料 = 网络_请求("GET", "https://api.example.com/me",
                  "{\"Authorization\":\"" + token + "\"}", "", 15, 2)
    界面_设置("状态", "欢迎，" + 对象文本(JSON_查询(资料, "name")))
    # 3) 下载头像（存 filesDir/me/avatar.jpg）
    网络_下载("https://api.example.com" + 对象文本(JSON_查询(资料, "avatar")),
            "me/avatar.jpg")
    # 4) 把头像传给服务器（multipart）
    上传 = 文件_上传("https://api.example.com/avatar",
                 "me/avatar.jpg", "{\"类型\":\"用户头像\"}",
                 "{\"Authorization\":\"" + token + "\"}")
    如果 上传 == "1":
        界面_设置("状态", "头像上传成功")
    否则:
        界面_设置("状态", "头像上传失败")
    结束
```

> `JSON_查询` 非 JSON 字段返回空串汇入 `对象文本` 时注意判空；生产代码建议每步判断 `如果 ... == ""` 或 `ok` 字段。

## 7. 常见坑

| 坑 | 现象 | 解法 |
|----|------|------|
| 桌面没装 libcurl 开发库 | `网络_GET` 返回空串 | 无需处理：自动回退系统 `curl` 命令（需 PATH 中有 curl）；仍不行再编译加 `-DVUS_HAVE_CURL -lcurl` |
| 主线程联网 | Android 4+ 抛 `NetworkOnMainThreadException` | 已内置处理：桥内自动转子线程同步等待 |
| 路径不对 | 上传/读取失败 | APK 相对路径 = `filesDir`；绝对路径加 `/` 前缀 |
| 响应不是 JSON | `JSON_查询` 取不到值 | 先 `打印(响应)` 看原始文本；用 `JSON_解析` 失败保护 |
| 中文转义 | 头 JSON 拼错 | 字符串内引号要 `\"` 转义，键值放 JSON 对象里 |
| gitee raw 404 | `raw/…/version.json` 访问失败 | raw 地址里的分支名必须等于**目标仓库的默认分支**（有的仓库是 `master`、有的是 `main`）；不确定时先浏览器/curl 直接访问确认 |
